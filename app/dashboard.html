❓ Como criar o usuário (passo a passo)
  1. No Supabase, vá em Authentication (menu lateral)
  2. Clique em Users → Add user
  3. Preencha o e-mail que deseja usar (ex: admin@kayla.app)
  4. Coloque uma senha (mínimo 6 caracteres)
  5. ✅ Marque "Auto Confirm User" (importante!)
  6. Clique em Create user
  7. Agora volte aqui e use esse e-mail e senha para entrar
